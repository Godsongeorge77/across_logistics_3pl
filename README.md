# ACROSS LOGISTICS — 3PL Secure & Trackable Goods Delivery System (Streamlit Edition)

## Deployment on Streamlit Community Cloud
1. Upload `app.py` and `requirements.txt` to your GitHub repository.
2. On Streamlit Cloud, set the main file path to `app.py` and click **Deploy**.

## Local Execution
```bash
pip install -r requirements.txt
streamlit run app.py
```
